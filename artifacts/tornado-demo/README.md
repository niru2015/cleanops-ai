# Tornado demo artifacts

`npm run demo:tornado` writes `screenshots/`, `videos-and-traces/`, `html-report/`, and `results/` here. Generated media and results are ignored by Git; this README preserves the folder layout. Open `html-report/index.html` after a run. See [TORNADO_DEMO.md](../../TORNADO_DEMO.md) for setup, evidence limits, and the Canva handoff.
